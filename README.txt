SMART HOSPITAL - Eclipse Project
=================================

This is the edited version of the Smart Hospital DSA project.

Included:
- CO1: Naive, KMP, Z, Rabin-Karp
- CO2: Suffix Array, Kasai LCP, Suffix Array Search, Suffix Automaton
- CO3: Levenshtein, Damerau-Levenshtein, Weighted Edit Distance,
       Needleman-Wunsch, Smith-Waterman, Bitmask DP
- Hospital modules: patients, appointments, medical records, search
- Console-based real-world hospital menu

Eclipse:
1. Import this folder as an Existing Eclipse Project.
2. Run src/smarthospital/Main.java as Java Application.

Note:
- No compiled bin folder is included.
- Eclipse may create bin automatically when the project is built..
